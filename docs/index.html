01 / 是什么

一个能自己联网、自己开门的 Linux 救援系统

它不修你的系统，它是给你一个能用的系统 —— 然后把门打开，让懂的人进来。

把镜像写进 U 盘，插到一台开不了机的电脑上启动，系统会尝试联网、拉起 sshd， 并把连接信息打到屏幕上。整个过程不需要图形界面，也不要求这台机器原本还能用。

和装系统不同，它默认不碰你的硬盘：救援界面只读取信息， 对目标磁盘的写入只在你明确选择之后才发生。

  • 原系统盘完全损坏
  • 没有操作系统
  • 缺网卡驱动
  • 显卡驱动异常
  • 内存不大

以上情况系统仍可运行。

01

懂的人，常常不在现场

电脑出故障时，能处理它的人往往在另一个城市。现场的人不用学任何命令 —— 插盘、开机，然后把屏幕上的几行字念给电话那头。

02

需要反复试错的故障

修 Windows 引导记录、清异常启动项、改注册表关掉反复失败的更新、排查驱动或更新引起的循环重启 —— 这类活要一边查资料一边试，AI 比现场的人更有耐心。

03

Windows PE 之外的第二条路

PE 对非 Windows 文件系统的读写有限，对较新的存储与文件系统支持滞后，还依赖 Windows 组件。这里是一整套 Linux：NTFS、ext4、XFS、Btrfs 都能直接读写。

对比项AI Boot ProWindows PE

02 / 怎么用

从一块 U 盘，到一条 SSH 连接

四步。前两步在现场，后两步在远程。

STEP 01

写入 U 盘

≥ 4 GB 的 U 盘，写入会清空整块盘。用 dd、Rufus、balenaEtcher 或 Ventoy 都行 —— 镜像含 hybrid MBR，写进去之后 BIOS 与 UEFI 都能引导。

STEP 02

开机从 U 盘引导

开机时按 F12 / F11 / F8 / ESC（视机型而定），在启动菜单里选那块 U 盘。

STEP 03

屏幕自己给出凭据

急救模式零输入：先试 U 盘里的配置，再试有线，再试上次成功的 WiFi，然后试手机热点，最后自己开一个热点。每一步的结果都写在屏幕上。

STEP 04

远程登入

ssh -p 22 ai@<IP>，sudo su - 免密提权。登录后先读镜像里的 AI-README.txt。

# 屏幕给出的连接信息
ssh -p 22 ai@192.168.1.23

# 登录后（密码为屏幕上的随机 16 位数字）
ai@aiboot:~$ sudo su -
root@aiboot:~# cat /usr/local/share/ai-boot/AI-README.txt
i

密码只出现在屏幕上

随机生成，不上传任何服务器，也没有遥测回传。任何看到这块屏幕和密码的人都能以 root 登录，所以不要在不可信的环境里开机。

i

给远程 AI 的说明书

AI-README.txt 是写给对面那个 AI 的：有哪些工具、能碰什么、什么绝对不许碰。它比人更容易忘记边界。

06 / 从源码构建

一次构建只要一条命令，代价是 25 分钟

Linux 环境，无需 root。需要 xorriso、squashfs-tools-ng，以及一份 Debian Live 13 amd64 standard ISO 作为底子。

# 工具链
sudo apt-get install -y xorriso squashfs-tools-ng

# 解包底子 → 覆盖 overlay → tar2sqfs(zstd) → 加 hybrid MBR → 出 ISO
bash tools/build.sh
1

不要复用上一次的构建产物

否则历次改动会层层叠加，你永远不知道镜像里到底是什么。

2

不要用 tar --delete 删文件

GNU tar 会一并丢弃 PAX 长文件名头，一批文件会被静默改名。

3

非 root 解包会丢 setuid 位

passwd、sudo、mount 等文件需要重新设置权限，否则镜像能引导、但登不进去。

4

/run 是 tmpfs

放进镜像 /run/ 下的文件在启动后会被覆盖。面向用户或 AI 的文件应放在 /usr/local/share/ 下。

为什么不把镜像塞进 Release？这一版 2.15 GiB，超过 GitHub 单文件 2 GiB 上限。项目的选择是：GitHub 只放源码与说明，镜像走网盘，不做分卷 —— 分卷会让「下载一个镜像」变成一次手工拼装，出错率太高。

08 / 已知限制

它做不到的事，也写在这里

  • 不做图形界面。所有操作都在文本控制台完成。
  • 不会主动修改原系统。救援界面本身只读取信息；对目标磁盘的写入，只在你明确选择之后才发生。
  • 远程接入需要能联网。完全无法联网时，系统只能提供本地指引。
  • 手机 USB 共享依赖机型。需要手机与内核驱动配合，并非所有机型都可用。
  • 中文字形受字体限制。界面用 512 字形的控制台字体，约 415 个汉字；不在子集内的中文 SSID 或路径会显示成方块。
  • 只维护当前版本。历史版本不再更新，也不在公开仓库里。
